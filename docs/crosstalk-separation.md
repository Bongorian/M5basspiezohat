# 弦間クロストークの分離・校正学習

5個のピエゾを別チャンネルで取得しても、ブリッジを介して信号が混ざる可能性がある。分離処理を導入する場合は、機械構造・ADC同期・校正データを先に評価する。本資料の分離方式は設計候補であり、実機の分離性能は未測定。付属ファームウェアのリアルタイム経路にはまだ分離係数を適用しない。

## 分離対象

| 現象 | 対応 |
| --- | --- |
| 回路・配線の電気的漏れ | 入力パッドへ既知信号を与え、他入力との比を測定。配線・GND・前段を確認 |
| サドル・ブリッジの機械的伝達 | 単独弦の校正からチャンネル間の振幅・位相・周波数特性を推定 |
| 隣の弦の共鳴 | 隣の弦も実際に振動している。奏者の意図を信号だけから完全に判別できるとは限らない |
| 複数弦を同じ音程で演奏 | 正しい同時演奏。単純な「同じ周波数を検出した弱い入力を消す」規則を適用しない |
| ADC間の固定遅延・スロット誤り | 同一電気信号を両ADCで測り、入力対応と同期を先に修正 |
| ADC／前段のクリップ | 混合後の情報が失われるため、分離で復元しようとせず入力振幅を修正 |

独立ピックアップでも漏れと共鳴は生じ得る。[Laguerre・Scavoneのhexaphonic pickup研究](https://www.dafx.de/paper-archive/2021/proceedings/papers/DAFx20in21_paper_2.pdf)も両者を扱っている。磁気ピックアップの研究結果を、ピエゾブリッジの漏れ率や達成性能として転用しない。

## 推奨する順序

1. **機械構造と実測**：各弦を単独で鳴らし、全入力を同期録音する。弦を押さえていない状態と他弦をミュートした状態の両方を測る。サドル隔離、支持方法、接触圧の変更で漏れが減るか確認する。
2. **固定混合行列**：振幅比と極性が比較的一定なら、4×4／5×5の正則化逆行列を評価する。追加遅延がほぼなく、計算量が少ない。
3. **短いFIR行列**：残留漏れに位相差や周波数依存がある場合、周波数ごとの複素混合特性を学習し、短い因果FIRへ近似する。必要な共通遅延を決める。
4. **発音判定の補助**：分離後の音程、独立したアタック、校正で求めた漏れ上限を組み合わせる。単独信号で説明できない残差信号を本当の別弦の候補として扱う。

初期導入では学習・係数計算をPCで行い、M5StickS3は固定係数の実行に集中する。演奏しながら係数を自動更新すると、同音や倍音が重なる正しい演奏を漏れとして学習し、消してしまう可能性がある。学習は明示した単独弦校正区間に限定する。

## 固定混合行列のモデル

観測を `x=H s+n` とし、Hの列iを「弦iを単独で鳴らしたときの各センサーへの伝達」とする。Hの対角を1とした相対尺度を使う。各単独弦録音のDCを除去し、主入力に対する符号付き最小二乗比を計算する。

```text
H[j,i] = median_over_clips( sum(x_j*x_i) / sum(x_i*x_i) )
W = inverse(H^T H + λ I) H^T
s_est = W x
```

λを増やすと逆行列のノイズ増幅を抑えやすいが、残留漏れと振幅の縮小も増える。完全な復元や正しいVelocityを保証しない。Hがほぼ特異なら、元の弦信号を安定に区別できない。単独の生ピエゾ振幅を真の弦運動として測定できているわけでもないため、校正チャンネルの相対尺度として解釈する。

### 付属のオフライン学習ツール

`firmware/tools/crosstalk.py` はPython標準ライブラリだけで動く評価用ツール。同期16kHz、正規化振幅−1〜1、列名 `J1,J2,J3,J4[,J5]` のCSVを受け取る。CSVは別途取得する。現在の `slots`／`status` は要約値であり、この校正用の同期波形を出力する機能ではない。

校正マニフェスト例：

```json
{
  "sample_rate": 16000,
  "channels": 5,
  "clips": [
    {"string": 1, "file": "B_open_01.csv"},
    {"string": 2, "file": "E_open_01.csv"},
    {"string": 3, "file": "A_open_01.csv"},
    {"string": 4, "file": "D_open_01.csv"},
    {"string": 5, "file": "G_open_01.csv"}
  ]
}
```

`string` はJ番号。各CSVは全4／5入力を含み、鳴らす弦だけを変える。複数録音は `clips` へ追加する。

```sh
python3 firmware/tools/crosstalk.py fit calibration/manifest.json model.json --ridge 0.01
python3 firmware/tools/crosstalk.py apply model.json validation/chord.csv separated.csv
python3 -m unittest discover -s firmware/tests -p 'test_*.py'
```

モデルには混合・分離行列、録音間の係数偏差、条件数、最大行和によるノイズ増幅上限を記録する。各弦の録音がない、振幅不足、クリップ、非有限値、特異行列、条件数30超、ノイズ増幅上限3超の場合は学習を拒否する。閾値とλ=0.01は評価開始値。未知の実機特性に対する保証値ではない。分離出力はクリップせず、増幅や残差を確認できるようにする。

合成テストでは既知の瞬時混合、極性反転、4／5入力、同音の同時演奏、分離不能な混合を確認する。実録音の有効性や周波数依存の分離は確認していない。ツールはモデルを本体へ自動配布しない。

## 校正録音の条件

- ゲイン、サンプルレート、スロット順、弦・ブリッジ取り付けを固定する。
- 各弦で開放・5・12・19フレットを中心に、弱／中／強、指／ピック、複数回のアタックを記録する。録音の一部は学習に使わず検証へ回す。
- 無音区間でノイズ床を測る。強く鳴らしたチャンネルがクリップする録音は使わない。
- 他弦をミュートした学習だけで済ませず、ミュートしない単独弦、実際のコード、同音・オクターブ・5度、弱い別弦のアタックでも評価する。
- アタックと持続部で係数が変わるか、チューニング、弦交換、接触圧、楽器の保持方法でモデルが変わるか調べる。

ピックアップ変換のFIR研究では、学習・評価する音程や弾き方の違いが誤差へ影響した。[Mohamad・Dixon・Harteの研究](https://dafx.de/paper-archive/details/KVQINF232FWbIIXsBVbgVw)を、校正条件を広げる理由として参照する。

## 固定行列で足りない場合

周波数領域で `H[j,i,f]` の複素振幅を推定し、ノイズの大きい周波数を除外しながら正則化する。単一の持続正弦波ではFIR全体を特定しにくいため、複数の音程・アタックを含む録音を使う。推定したWを因果FIR行列へ近似し、先行成分のための共通遅延とフィルタ長を設定する。

実装候補は共通DC除去・LPF・4kHz間引きの後、YINの前へ置く32タップ程度の5×5 FIR。計算量は `5×5×32×4000 = 3.2M MAC/s`、係数・履歴は数kB程度。これは演算回数の計算であり、ESP32-S3でのCPU余裕は未測定。ブロックFFT方式はブロック待ち時間が増えるため、既存の音程観測時間に加えて測定する。

モデルを導入する条件は、未使用の検証録音で漏れ由来の誤Note Onが減り、弱い実音・同音同時演奏・アタックが失われず、P95遅延と取得欠損が悪化しないこと。適用を切り替えて比較できるバイパス、楽器ごとの係数保存、モデル形式・スロット順・ゲインの一致検査を設ける。

単独弦の波形を混合した検証だけでは実楽器の共鳴を再現できない。実演奏の正解ラベルと比較し、必要なら機械構造に戻って改善する。
