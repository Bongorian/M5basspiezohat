# StickS3 Hat2用ピエゾADC Hat・R1コンパクト機構案

2026年10月6日更新。ユーザー指定は **Hat単体でコネクタ込み48×24×15mm以内**。装着した本体との合計寸法ではない。以前の21×45mm基板・49mm外装案を置き換える。

| 項目 | 現行案 |
| --- | --- |
| 基板 | 21×38mm、厚さ1.0mm、4層、四隅R1mm |
| 実装 | 部品は表面のみ。裏面は裸のテストパッド4個 |
| ケース本体 | 長さ41.1×幅23.8×厚さ14.8mm |
| コネクタ先端を含むモデル計算 | 長さ46.98×幅23.8×厚さ14.8mm（汎用3Dモデル） |
| 側壁／背壁 | 1.1mm。内幅21.6mm、基板左右の隙間は各0.3mm |
| Hat2 | BXCONN PZ-2.54-2*08-8.5-WZ／C53207371を候補とし手はんだ |
| ピエゾ | 5組のSIG／GND内部パッド。穴0.8mm、径1.8mm、各組の穴間2.5mm |

StickS3の公称寸法とHat2端子表は [メーカー資料](https://docs.m5stack.com/en/core/StickS3) を参照。候補ヘッダの [メーカー図面の掲載ページ](https://www.lcsc.com/product-detail/C53207371.html) にあるピン列から先端までの6.9±0.2mm＋6.0±0.2mmを使うと、コネクタ込みの公称寸法は **長さ47.3×幅23.8×厚さ14.8mm**。コネクタの長手方向公差+0.4mmとケース／配置の予算+0.2mmを見込んだ長さは47.9mm。汎用3Dモデルは図面より先端が約0.32mm短いので、その見た目だけで寸法判定しない。これらは設計予算で、実機嵌合・造形精度による寸法保証ではない。

## 基板の固定案

**基板の固定穴・固定用切り欠きは現在なし。** 四隅R1mmは外形の丸みで、固定機能ではない。小さい基板の部品領域を確保するため、筐体側で基板の外周を支える案を3Dに追加した。

- 左右のガイド溝：厚さ1.0mmの基板に対して溝幅1.2mm。基板端の0.3mmを表裏から支える。造形公差と組み立ての隙間は試作で調整する。
- 上端の受け：基板が上へ動くのを止める。
- 下端の取り外せる受け：基板を下から差し入れた後に取り付ける想定。コネクタの挿抜時に基板が下へ動くのを止める。

下端の受けを筐体へ留める方法と蓋の留め方は未設計。このモデルは固定構造の位置を示す案であり、組み立て済みで保持できる製造図ではない。追加の固定穴や切り欠きが必要になった場合は、部品配置・配線と合わせて再検討する。

## 部品を詰めた方法

TLV9064を3×3mm WQFNにし、5入力＋中点バッファを2個で構成。LPFは受動RCに変更し、部品本体と標準フットプリントのコートヤードを確認して受動部品を配置する。部品外形を重ねて小さく見せる配置にはしていない。

テストポイントは裏面の裸銅箔へ移動した。裏面実装や二度目のリフローは不要。ヘッダの樹脂部と挿入ピンを下端へ寄せ、ケースの下端から差し込みピンを出す。ピンをケース内に隠して挿入できなくなる形にはしない。

## ケースとして残る設計

コンパクト3Dは現行KiCad基板のGLBを読み込んでおり、ICとヘッダは同等外形のパッケージモデル。ケースは占有寸法の確認用で、製造用の筐体ではない。下端の受けと蓋の固定、ケーブル出口・外被クランプ、Hat2周辺の位置決めを確定する必要がある。

Hat2の挿入・干渉・保持は実機で照合する。コネクタ型番と向きを決めてから、公式端子番号のGND／EXT_5V位置を導通確認し、コネクタだけの試作で挿入を確認する。内部回路図のCN2番号と外部Hat2端子表の番号は異なるので、番号だけで照合しない。

ピエゾ線は上側の穴付きパッドに接続し、ケース出口で外被を固定する。高抵抗前段付近のフラックスを清掃し、接着剤やケーブルの力が入力部へ直接かからない組み立てにする。
