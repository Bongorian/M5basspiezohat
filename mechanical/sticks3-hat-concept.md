# R1筐体検討モデル

M5StickS3 Hat2用基板の寸法と外周保持を検討するBlenderモデル。設計範囲はHat単体・コネクタ込み48×24×15mm以内。蓋・下端受けの固定方法とケーブル出口は未設計で、モデルをそのまま製造用筐体として使用できない。

## 寸法

| 項目 | 設計値 |
| --- | --- |
| 基板 | 21×38×1.0mm、4層、四隅R1mm |
| ケース本体 | 長さ41.1×幅23.8×厚さ14.8mm |
| コネクタ込み公称値 | 長さ47.3×幅23.8×厚さ14.8mm |
| 長さの公差予算 | 47.9mm |
| 汎用3Dモデルによるコネクタ込み値 | 長さ46.98×幅23.8×厚さ14.8mm |
| 側壁・背壁 | 1.1mm |
| 内幅・基板の隙間 | 内幅21.6mm、左右各0.3mm |
| Hat2ヘッダ | BXCONN PZ-2.54-2*08-8.5-WZ／C53207371、嵌合未検証 |
| ピエゾパッド | SIG/GND×5組、穴0.8mm、銅箔径1.8mm、各組の穴間2.5mm |

ヘッダの [メーカー図面掲載ページ](https://www.lcsc.com/product-detail/C53207371.html)にある6.9±0.2mm＋6.0±0.2mmを使用した公称長は47.3mm。コネクタ公差+0.4mmとケース・配置公差+0.2mmを加えた設計予算は47.9mm。汎用パッケージモデルの先端は図面より約0.32mm短いため、寸法判定はメーカー図面を基準とする。実機嵌合・造形精度は未検証。

## 基板保持

基板に固定穴・固定用切り欠きはなく、筐体側のガイドと受けで外周を支える構成。

- 左右のガイド溝：幅1.2mm。厚さ1.0mmの基板端を0.3mmの範囲で支える。
- 上端の受け：基板の上方向の移動を制限する。
- 下端の受け：基板を下から差し込んだ後に装着する取り外し式の部品を想定。固定方法は未設計。

部品は表面のみ、テストパッドは裏面の裸銅箔。ヘッダの接点はケース下端から突出する。モデルのIC・ヘッダは汎用パッケージ形状で、製品固有の嵌合保証を含まない。

## 組立時の確認項目

Hat2ヘッダの向き、挿入長、干渉、保持力を実機で確認する。GND／EXT_5V位置は [M5公式端子表](https://docs.m5stack.com/en/core/StickS3)と導通で照合する。内部回路図のCN2番号と外部Hat2端子番号は異なる。

ピエゾ線は上側の穴付きパッドへ接続する。ケース出口の外被固定、接着剤の配置、入力部へ伝わる引張力を評価する。高抵抗入力部はフラックスを清掃する。
