# M5basspiezohat R1 — 製造・組立手順

実機未検証の試作基板。製造データはKiCad 9.0.9で未接続・DRC・ERC各0件、回路図・基板・設計マニフェスト318接続の照合済み。PCBAは101点、全点Top。

## 製造ファイル

`hardware/sticks3-piezo-hat/release/` に次のファイルを格納している。`PCBA_JLCPCB.zip` は製造用データの一式。

| ファイル | 用途 |
| --- | --- |
| `Gerber_JLCPCB.zip` | 4層銅箔、表裏マスク、表面ペースト、表裏シルク、外形、PTH／NPTHドリル、Gerberジョブ |
| `BOM_JLCPCB.csv` | PCBA用のLCSC部品番号・参照名 |
| `CPL_JLCPCB.csv` | 101点の配置座標・回転、単位mm、Topのみ |
| `rotation-audit.csv` | KiCad角度・JLC補正値・補正後角度・基板のピン1座標。座標はCPLと同じmm／左下原点 |
| `assembly-front.png` | 部品位置とピン1の照合図。赤いリングはピン1 |
| `HAND_ASSEMBLY.csv` | 手実装するヘッダ、ピエゾ配線 |
| `BOM_full.csv` | 全部品の数量と実装分担 |
| `manifest.json` | ZIP・BOM・CPL・組立図のSHA-256とファイルサイズ |

## 基板条件

| 項目 | 指定値 |
| --- | --- |
| 材質・層数 | FR-4、4層 |
| 外形・厚さ | 21×38mm、1.0mm、四隅R1mm |
| 銅厚 | 外層1oz、内層標準0.5oz |
| 層構成 | F.Cu／In1.Cu（GND）／In2.Cu（信号）／B.Cu |
| マスク・実装面 | 緑、表面PCBA |
| 最小配線幅・間隔 | 0.10mm／0.10mm |
| 外形から銅箔 | 0.5mm以上 |
| ビア | 貫通、外径0.40mm、穴0.20mm、表裏テント |
| マスク開口 | 銅箔パッドと1:1 |

SMDペースト領域とビア穴の重なりは0件。裏面はTP1〜TP4の裸銅箔で、実装部品はない。

JLCPCBでは穴0.20mm・外径0.45mm未満のビアに追加料金条件がある。注文時の [基板能力表](https://jlcpcb.com/capabilities/pcb-capabilities) と小径ビア設定を確認する。小型基板のパネル／治具条件は利用する実装サービスで確認する。

## PCBA発注

1. `Gerber_JLCPCB.zip`を読み込み、外形・4層・厚さ1.0mmと上記の基板条件を確認する。
2. 表面実装を選択し、`BOM_JLCPCB.csv`と`CPL_JLCPCB.csv`を読み込む。
3. 101点の参照名、Top面、LCSC品番、在庫、実装区分、調達価格を確認する。
4. `assembly-front.png`と配置プレビューを比較する。特にU1〜U6のピン1と回転、QFN露出パッドを照合する。
5. `HAND_ASSEMBLY.csv`の部品とピエゾ線を別途準備する。

LCSC販売在庫とJLCPCB実装用在庫は個別に確認する。D1〜D5を含む全SMD部品101点をPCBA対象とする。J6ヘッダとピエゾ線は手実装。D1〜D5のC51315120が部品照合で未登録／調達不可の場合は、欠品のまま確定せずJLCPCBの部品調達を設定する。同名のBAV199Wでもメーカー・内部結線・ピン配列を照合せず置き換えない。

## CPLの回転と実装確認

CPLへKiCadの角度をそのまま転記せず、`jlc-rotation-corrections.json`の品番別補正を適用する。Top面で `JLC角度 = (KiCad角度 + 補正) mod 360`。実装座標と基板上のパッド・配線は変更しない。

| 部品 | KiCad角度 | 補正 | CPL角度 | 基板上の向き（表面） |
| --- | ---: | ---: | ---: | --- |
| U1・U2 / C882406 | 0° | 0° | 0° | ピン1は左上側 |
| U3・U4 / C365743 | 0° | 270° | 270° | ピン1は左上側 |
| U5・U6 / C51118 | 0° | 270° | 270° | 左に3端子、右に2端子。ピン1は左上 |
| D1〜D5 / C51315120 | 90° | 270° | 0° | ピン1＝左下GND、2＝右下3V3A、3＝上のHI入力 |

U3〜U6の補正は旧CPLを読み込んだ配置画像の部品マーク・端子列と基板パッドの比較に基づく。D1〜D5は新規追加のため、SOT-323の基準姿勢に基づく補正を新しいJLCPCBプレビューで確認する。新品番・別メーカーへの置換では同じ補正が適用できるとは限らない。

アップロードには補正済み`CPL_JLCPCB.csv`を使う。`CPL_KiCad.csv`は未補正の検査用で、発注には使わない。新データのJLCPCBプレビュー／DFMはまだ確認していない。`assembly-front.png`の赤いリングは基板の実際の1番パッドを示す。JLCPCBの色付き点だけをピン番号と解釈せず、端子列・メーカーのピン配置と合わせて照合する。[JLCPCBの配置・向きの説明](https://jlcpcb.com/help/article/pcb-assembly-faqs-part-2)

## 手実装と通電前確認

1. PCBA済みのD1〜D5のBAV199W保護ダイオードがすべて実装され、組立図のピン番号と一致することを確認する。
2. J6ヘッダを取り付ける。C53207371の嵌合は未検証のため、M5StickS3実物で向き・挿入長を確認する。
3. J1〜J5のSIG／GNDへ弦別ピエゾ線を接続する。高抵抗入力部のフラックスを清掃し、線材への引張力を筐体側で受ける。
4. GND・EXT_5Vの端子位置、電源短絡、ダイオード方向を確認する。端子番号は外部Hat2端子表を基準にする。
5. 本体初期化後にEXT_5Vを有効化し、3V3A／3V3D・VMIDとI²Cアドレスを測定する。EXT_5Vの出力モードでは同端子へ別電源を接続しない。

## 動作評価

ADC単体取得から2個カスケード取得へ進み、スロット対応、Low Bの低域応答、クリップ回復、弦間漏れを測定する。U4の割り込み出力はNCのため、ADC初期設定で割り込みを無効にする。

音程検出・USB MIDIのESP-IDFファームウェアをリポジトリに収録。ビルドと合成信号テストは確認済み、実機は未検証。[導入・診断手順](https://github.com/Bongorian/M5basspiezohat/tree/main/firmware)に従って書き込み、入力スロットを確認する。標準はUSBデバイスで接続先にUSBホスト機能が必要。USBホストモードも搭載するが、StickS3はUSB-Cへ給電しないため、音源側への外部VBUS給電が必要。筐体モデルは寸法・保持構造の検討用で、固定部とケーブル出口は未設計。

接続表・評価条件は [M5basspiezohatリポジトリ](https://github.com/Bongorian/M5basspiezohat) の基板仕様とファームウェア設計を参照。
